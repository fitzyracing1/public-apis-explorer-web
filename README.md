# public-apis-explorer-web

**Web UI version** for Termux — Self-delivered by the persistent-self-coder skill

A clean, mobile-friendly web interface to explore popular public APIs. Works great in Termux.

## How to run in Termux

```bash
# 1. Install Flask
pkg update && pkg install python
pip install flask

# 2. Clone this repo
git clone https://github.com/fitzyracing1/public-apis-explorer-web.git
cd public-apis-explorer-web

# 3. Run the web app
python app.py
```

Then open **http://localhost:5000** in your phone's browser.

## Features
- Works completely offline
- Clean mobile-friendly design
- Search by keyword
- Shows category, auth, HTTPS, and CORS info
